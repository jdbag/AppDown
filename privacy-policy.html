آخر تحديث: 2026

هذا التطبيق ("اختبار دفع Pi") هو تطبيق تجريبي يعمل داخل Pi Browser ويستخدم Pi SDK لإتمام عمليات الدفع عبر شبكة Pi.

المعلومات التي نجمعها

  • اسم المستخدم (username) الذي توفره منصة Pi عند تسجيل الدخول عبر Pi.authenticate().
  • معرّف المستخدم (uid) الخاص بشبكة Pi، المستخدم فقط لإتمام عمليات الدفع.
  • بيانات عمليات الدفع (رقم العملية، القيمة، حالة العملية) اللازمة لإتمام المعاملة عبر Pi Platform API.

كيف نستخدم هذه المعلومات

نستخدم هذه المعلومات حصراً لإتمام عمليات الدفع (استلام أو إرسال Pi) والتحقق من هوية المستخدم عبر واجهة Pi الرسمية. لا نقوم ببيع أو مشاركة بياناتك مع أي طرف ثالث.

تخزين البيانات

لا يقوم هذا التطبيق بتخزين بيانات دفع حساسة على خوادمه بشكل دائم؛ التحقق من صحة المعاملات يتم مباشرة عبر خوادم Pi Network.
