شروط الاستخدام

آخر تحديث: 2026

باستخدامك لهذا التطبيق ("اختبار دفع Pi") داخل Pi Browser، فإنك توافق على الشروط التالية.

طبيعة التطبيق

هذا التطبيق هو تطبيق تجريبي (اختباري) يستخدم Pi SDK لإجراء عمليات دفع صغيرة عبر شبكة Pi Network، بهدف الاختبار والتطوير.

استخدام الحساب

  • يجب تسجيل الدخول عبر حساب Pi صحيح ومصادق عليه من طرف منصة Pi Network.
  • أنت مسؤول عن صحة العمليات التي توافق عليها داخل التطبيق.
  • يُمنع استخدام التطبيق لأي غرض احتيالي أو غير قانوني.

المدفوعات

جميع عمليات الدفع (استلام أو إرسال Pi) تتم عبر واجهة Pi Platform API الرسمية، ويتم التحقق منها وتأكيدها عبر خوادم Pi Network. لا يتحمل مطوّر التطبيق مسؤولية أي خلل ناتج عن شبكة Pi نفسها.

التعديلات

يحتفظ مطوّر التطبيق بالحق في تعديل هذه الشروط أو ميزات التطبيق فى أي وقت دون إشعار مسبق، نظراً لكون التطبيق في مرحلة تجريبية (Testnet/Development).

إخلاء المسؤولية

هذا التطبيق يُقدَّم "كما هو" دون أي ضمانات، ولا يتحمل المطوّر مسؤولية أي خسارة مالية ناتجة عن استخدامه، خصوصاً خلال مرحلة الاختبار.

التواصل معنا

لأي استفسار بخصوص هذه الشروط، يمكن التواصل عبر صفحة GitHub الخاصة بالمشروع.
